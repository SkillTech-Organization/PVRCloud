# Általános leírás {#általános-leírás}

PVRPCloudAPI gyűjtő-terítő feladatok optimalizálását végző API. A PVRPCloudRequest hívással \- amennyiben a bemenő paraméterek helyesek- asszinkron elindul egy számjtási folyamat. A visszakapott requestID-vel a PVRPCloudResult végponton kereszül kérhető le az eredmény

A [Példa PVRPCloudRequest  hívás body](#példa-pvrpcloudrequest-hívás) fejezetben található json adatstruktúrával hívott [PVRPCloudRequest](#optimalizálás-kérés:-v1/pvrpcloudrequest) végponra fix 12345678 RequestID \-vel rendelkező http202-es válasz érkezik vissza.  A bemenő adatok validációja is megtörténik, így a kliens hibaágak is fejleszthetőek/tesztelhetőek, ‘elrontott’ jsonnal (pl. helytelen járműtípus/jármű összerendelés megadásával)   
A [PVRPCloudResult](#optimalizálás-eredmény-lekérdezése:-v1/pvrpcloudresult/\<requestid\>)/12345678 hívással a [Példa PVRPCloudRequest  hívás body](#példa-pvrpcloudrequest-hívás) fejezetben küldött adatra valid eredmény kerül visszaadásra, ami a [Példa PVRPCloudRes eredmény body](#példa-pvrpcloudres-eredmény-body) fejezetben található. Ha nem 12345678 requesrID-vel kérünk ki eredményt a válasz http404 lesz.

### HTTP válaszkódok {#http-válaszkódok}

* **202**: A kérés befogadva,  a bemenő paraméterek validációja nem eredményezett hibát.  A feldolgozás asszinkron módon elindul.  
  Visszatérés body-ban. PVRPCloudResponse.PVRPCloudResponse.**Result** lista 1 db RESULT típusú tételt tartalmaz, amelyben a **Data** mező PVRPCloudProject  További leírás az ‘API válaszok’ fejezetben  

* **400**: A kérés bemenő paramétereiben validációs hiba van.   
  Visszatérés body-ban. PVRPCloudResponse.PVRPCloudResponse.**Result**  lista több  VALIDATIONERROR típusú tételt tartalmaz, amelyben a **Data** mező PVRPCloudResErrMsg objektum. További leírás az ‘API válaszok’ fejezetben  
  
  Ha a validálás során hibás adatot talál a program, nincs további feldolgozás\! 

* **401**: Authorizációs hiba. Helytelen vagy hiányzó API key. Más visszatérési érték nincs  

* **500**: A kérés befogadása közben nem kezelt kivétel Visszatérés body-ban. PVRPCloudResponse.PVRPCloudResponse.**Result** lista  egy EXCEPTION típusú tételt tartalmaz, amelyben a **Data** mező PVRPCloudResErrMsg objektum. További leírás az ‘API válaszok’ fejezetben  
  
  Nem kezelt kivétel esetén nincs további feldolgozás\!

### HTTP válaszkódok {#http-válaszkódok-1}

* **200**: A megadott requestID-re van eredmény.  
  Visszatérés body-ban.PVRPCloudResponse.**Result** lista 1 db RESULT típusú tételt tartalmaz, amelyben a **Data** mező PVRPCloudProjectRes További leírás az ‘API válaszok’ fejezetben  
  Visszatérés body-ban.PVRPCloudResponse.**Result** lista 1 db RESULT típusú tételt 

* **401**: Authorizációs hiba. Helytelen vagy hiányzó API key. Más visszatérési érték nincs  

* **404**:  A megadott RequestID-re nem létezik eredmény. Más visszatérési érték nincs.  

* **422**: Végstátusz, belső hiba miatt nincs számítási eredmény.  

* **500**: A kérés befogadása közben nem kezelt kivétel Visszatérés body-ban. PVRPCloudResponse.**Result** lista egy EXCEPTION típusú tételt tartalmaz, amelyben a **Data** mező PVRPCloudResErrMsg objektum. További leírás az ‘API válaszok’ fejezetben  

* **504 :** Végstátusz, a számítás eredmény nélkül, timeouttal megszakadt.   
  
  Nem kezelt kivétel esetén nincs további feldolgozás\!

#### PVRPCloudResponse osztály részletezése {#pvrpcloudresponse-osztály-részletezése}

public class PVRPCloudResponse  
{  
    public string RequestID { get; set; }  
    public List\<PVRPCloudResult\> Result { get; set; } \= new List\<PVRPCloudResult\>();  
    public bool HasError  
    {  
        get  
        {  
            return Result.Any(a \=\>  
                 a.Status \== PVRPCloudResult.PVRPCloudResultStatus.VALIDATIONERROR ||  
                 a.Status \== PVRPCloudResult.PVRPCloudResultStatus.EXCEPTION ||  
                 a.Status \== PVRPCloudResult.PVRPCloudResultStatus.ERROR);  
        }  
    }  
}

RequestID: sikeres feldolgozás esetén a kérés azonosítója  
Result : Egy listában a kérés eredményrészletezői (PVRPCloudResult)  
HasError: Van-e hiba típusú visszatérési érték

#### PVRPCloudResult osztály részletezése {#pvrpcloudresult-osztály-részletezése}

    Nem kezelt kivétel

* ItemID : nincs értelmezve  

* ResErrMsg: PVRPCloudResErrMsg objektum, mezői
  
  Field: nincs töltve

    Feldolgozás során felmerült üzleti hiba.
